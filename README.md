# Citadel | Citadel Securities Summer Invitational Terminal

### Custom algo based on [C1 Terminal Starter Kit](https://github.com/correlation-one/C1GamesStarterKit)

## Instructions

#### 1. Use the following Powershell command to simulate a match between the custom algo and the default bot.
```
scripts/run_match.ps1 my-algo default-bot
``` 

#### 2. Upload the corresponding `.replay` file in `replays` to the [Terminal Playground](https://terminal.c1games.com/playground) to view the game.
